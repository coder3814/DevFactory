# The issue or request

A core module of the [card standard](../card-standard.md).

## Holds

What prompts the change, in a few plain sentences: how things stand today and
why that falls short, or for a request, what someone cannot do or get today and
why that matters.

## Rules

It says so plainly ("Today…"), and a stated cause says whether it is confirmed
or suspected. It prescribes nothing to build.

Evidence is not reproduced here: measurements, sample data, walk-throughs of
code or files, and a stakeholder's verbatim words. A file is attached, or an
existing one pointed to, and this section names it. What is given when the card
is created, however much there is, is curated into the card's sections, keeping
only what a reader needs; what arrives later is recorded in a comment.
